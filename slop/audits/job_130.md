## Hypotheses

### H1 [method | Almost Certain | 90%]

- Mechanism: C=2 is over-relaxation. For coordinates `(a,b)`, one application changes their difference by `1-2C=-3`; repeated applications alternate and amplify it.
- Evidence: job 130 shows all one-layer rows healthy, while the stored eight-layer row has `KL=76.46316528320312` and `entropy=5.839451091560477e-07`.
- Contrary evidence: transformer blocks intervene between applications, so the pure `(-3)^8` recurrence is not the whole executed system.
- Discriminating test: cumulative L23, L23–24, …, L23–30 at C=2. A sharp rise in coordinate magnitude and KL with count supports composition; no progression would contradict it.
- Fix/action: reserve “swap” for C=1. Call C>1 extrapolation. Do not apply C>1 repeatedly without measuring coordinates.
- Interpretability: yes for diagnosing the prior Spider collapse; no for Ant steering.

### H2 [method | Chances a little less than even | 45%]

- Mechanism: L26 is a useful location where the selected Spider→Ant directions influence the downstream six-leg answer.
- Evidence: `residual_layer': 26 ... 'delta_logp6': 0.3345475196838379`, the largest increase, with KL=.00617 and entropy=.65946.
- Contrary evidence: top remains `8`, odds remain -3.125, and there is no random-direction comparison.
- Discriminating test: L26-only signed dose sweep and 32 norm-matched random directions. The targeted effect should rise smoothly and exceed random effects before KL becomes large.
- Fix/action: add the focused sweep to the existing script and generate only for stable top-`6` candidates.
- Interpretability: partial.

### H3 [measurement | Unlikely | 40%]

- Mechanism: the L26 p6 increase reflects generic movement among digit logits rather than Ant semantics.
- Evidence: the operation uses Spider/Ant token directions, but the endpoint is an unrelated output token `6`; L26 also reduces p8 from .88257 to .84758.
- Contrary evidence: p6 rises by a larger factor than the p8 reduction alone requires, and the direction was chosen independently of output token `6`.

- Fix/action: log digit-conditional probabilities and signed controls.
- Interpretability: partial; the layer screen remains valid, semantic attribution does not.

### H4 [bug | Remote | 8%]

2. Prediction check:

   - one layer produces useful Ant steering: unresolved; L26 moved p6 but did not make `6` top and lacks matched controls.
3. Earliest unsupported link: selected Spider/Ant LM-head rows → Ant-specific causal direction. A signed L26 sweep against norm-matched random directions would support it.
4. Validity: “invalid” means the saved layer comparison does not represent the executed clean revision or the metrics do not measure the stated rows. `P(invalid)≈0.05–0.10`; credible positive mechanism diagnostic, inconclusive causal-semantic result.
5. Highest-information clues: (1) all eight rows kept top `8`; (2) L26 gave the largest stable p6 movement; (3) clean provenance and complete 652-line log make source drift unlikely.
6. Missing metrics: (1) matched-random L26 distribution, (2) signed L26 dose curve, (3) mean-atomic two-direction condition number, (4) cumulative layer-count transition, (5) float32 logits.
7. Bugs requiring code changes: add the coordinate-contrast invariant; record direct prototype geometry; add a stage selector to avoid re-running old experiments.
8. Misconceptions requiring reinterpretation: C=2 is extrapolation, not “twice a swap”; the prior top-`Spider` result is repeated-operator collapse, not failed semantic movement toward Ant.

10. Recommended sequence: run the L26-only signed dose and matched-random screen now. Run a cumulative layer-count diagnostic only if the next code change requires a precise instability boundary. Do not combine layer count, dose, direction construction, and prompt changes in one comparison.
