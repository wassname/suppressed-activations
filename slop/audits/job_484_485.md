# Audit: jobs 484, 485, and 487, ant transfer and donor check

Job 484 tested the frozen spider-to-dog notebook configuration with only the donor prompt and
target answer changed from dog and 4 to ant and 6. It completed successfully. The result remained

Job 485 repeated the fixed condition inside the predeclared C=2, 2.5, 3, 4 grid. This independently
reproduced the C=2.5 values. No strength generated 6. The changes in `log p(6) - log p(8)` were
-0.625, -0.625, -0.750, and -0.375. At C=4, the first token became 2 while `p(6)` fell to 0.004487.

The unmodified ant donor readout was:

```python
['Social', 'social', ' vor', 'V', ' vaya', 'ocial', ' sociales', ' división']
```

This does not resemble an ant readout. The result therefore shows failure of this fixed
prompt-and-detector configuration. It does not isolate whether another ant wording would provide
a useful suppressed subspace.

token, and C=4: `p(6)=0.487144` and `p(8)=0.379388`. Since prompt format, layer, positions, and
strength all differ, that result establishes configuration sensitivity rather than transfer of the
new default.

generation and probability were correct, and the parser was generalized after the audit.
