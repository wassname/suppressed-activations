### Extraction and intervention

The method computes ordinary LM-head logits at early, peak, and output layers, scores each vocabulary row by the smaller positive rise and fall, selects the top rows, and QR-orthonormalizes their centered unembedding directions (`suppressed_activation_subspace.py:9-42`). The intervention is:

> `replaced = h + strength * (target - source)`

where source and target are projections into separately extracted sample bases; each target component is norm-matched to the source component and the final residual is norm-restored (`suppressed_activation_subspace.py:65-81`). At C=4 this is extrapolation beyond the C=1 replacement endpoint.

The final source token only is edited (`scripts/spider_ant_demo.py:529-550`). Each residual layer is tested in a separate forward, so the successful result does not depend on repeated edits to the shared residual stream.

## Second cause for the headline number

The headline is the pair of top-token changes at L26/C4. The code computes each by replacing the source projection with a norm-matched target projection and restoring the residual norm (`suppressed_activation_subspace.py:65-81`). The same numbers could arise if the target final residual carries only the answer digit/completion state, or if any large tangent perturbation redistributes probability among digits. Answer-only target components and distance-matched random rotations separate those explanations.

## What else could score well

A target prompt that already predicts the desired digit can score well by direct answer-state transfer. The target need not encode Ant or Dog semantics. Also, selecting one successful layer/dose pair from 64 rows inflates apparent reliability. A frozen rerun with arithmetic answer targets and matched random controls detects both shortcuts.

## Decision

1. **Resolve-condition verdict: met for discovery.** The condition was “use one site only if one L23-L30 layer gives both Ant-6 and Dog-4 crossings on fixed grid.” L26/C4 gives Ant top 6 and Dog top 4. It is not yet met for the plan’s matched-control discriminator.
2. **Prediction check:**
   - one shared useful layer: **supported** by L26/C4;
   - Dog needs repeated edits: **contradicted** by Dog L26/C4;
   - Ant target extraction is not useful: **contradicted for first-token transfer**, unresolved for Ant semantics.
3. **Earliest unsupported link:** the target subspace represents animal-specific content rather than an answer/completion state. Answer-only matched controls would support or reject this link.
4. **Validity:** Invalid means the saved top-token crossings do not correspond to the recorded one-site operator, prompts, and source revision. `P(result is invalid) ≈ 0.08–0.18`. Classification: **credible exploratory positive**, not confirmatory semantic evidence.
5. **Three highest-information clues:**
   1. One shared L26/C4 setting produces the two different intended top digits; this removes the repeated-layer explanation.
   2. Both candidate rows retain .998 digit mass; the crossings are structured redistribution among digits.
   3. The Ant basis is semantically opaque while its target prompt already answers 6; this sharply raises answer-state transfer as the leading explanation.
6. **Missing metrics, by expected information gain:** 256 matched-random expected-token effects; arithmetic answer-only target effects; byte-source and penultimate-position controls; exact 64-token generations; exact model/tokenizer revisions.
7. **Bugs requiring code changes:** H4 requires explicit C=0, layer-index, mask-position, and saved-residual assertions in the fixed confirmation script.
8. **Misconceptions requiring reinterpretation:** C=4 is extrapolation, not an exact swap. Selected vocabulary rows are basis diagnostics, not necessarily hidden thoughts. Distinct 8→6 and 8→4 changes do not yet prove Ant and Dog semantics.
9. **What would change the verdict:** Extreme fixed-condition percentiles against matched random controls and effects stronger than answer-only controls would support semantic transfer. Similar answer-only effects or common random crossings would reduce the claim to generic answer-state transfer.
10. **Recommended sequence:** preserve and commit job 149 as discovery evidence; implement one small fixed L26/C4 confirmation path with all high-information controls; run it once from a clean revision; audit it before changing README, figure, or notebook. Do not combine new layers, doses, prompts, or token-pair interventions in that confirmation.
