## Ranked hypotheses

1. H1 [harness, highly likely, 80%]: assistant-prefilled questions cause control errors. Evidence: ant-legs says `It does not provide the question.` in the linked job 762 condition. Contrary evidence: dog-name controls answer the animal correctly. Test/action: keep wording and weights fixed, place the question in the user turn, and run Base/donor first. H1 predicts correct task answers and less prompt commentary; persistent errors favor intrinsic model or prompt ambiguity. Interpretability: partial, current continuations remain observable but some task scores fail.

2. H2 [measurement, almost certain, 98%]: bare-token scores miss actual answers behind formatting. Evidence: job 760 has `first_token: "<think>"` and later `The animal is the **dog**.` Job 761 has `' No'` in the top table while bare `No` is scored. Current code at `scripts/oat_sweep.py:1157` uses `one_token(tokenizer, source_output)` and at line 1833 computes the four-term shift from those IDs. Contrary evidence: digit tasks sometimes answer directly. Test/action: compare complete-answer judgments against first-token scores on these saved outputs before a new run. Interpretability: yes for literal token movement, no for semantic ranking.

3. H3 [method, likely, 65%]: current ant displacement changes animal prose without selective ant transfer. Evidence: job 763 says `The animal is a **sugar glider**.` and job 764 names `tarantula hawk`. Contrary evidence: dog-name and dog-mammal produce coherent dog prose; bad ant controls may mask a useful displacement. Test/action: after clean controls, use one fixed ant-name task with C0 and matched-random direction plus ant displacement. Selective ant prose favors transfer; assorted animals across directions favors nonspecific disturbance. Interpretability: partial; this implementation did not show ant prose transfer, which does not reject suppressed-subspace steering in general.

4. H4 [bug, remote, 15%]: source edits during jobs alter comparison behavior. Evidence: paired dog-legs runner hashes `54003bd7...` and `1f880307...` differ; job 764 records another hash. Contrary evidence: recorded intervention config and extraction wording match, and edits may only concern logging. Test/action: root compares the exact changes; repeat one pair with fixed source only if edits affect execution. Identical math lowers this concern. Interpretability: partial until exact changes are checked. This hypothesis affects wrapper attribution, not whether the stored dog prose exists.

Unknown explanation retains roughly 10-20% weight. These are nonexclusive subjective bets, not measured frequencies. H1 also raises H2 because malformed controls make bare-answer interpretation weaker.

## Decision

Resolve condition `change only evaluation wrapper`: met at requested config level; not fully judgeable at executed-source level. The implied control repair is not met. Dog-name supplies the cleanest narrow positive animal-transfer example. Dog-mammal prose improves, while its first-answer contract still fails. Dog-legs has coherent transfer but a degraded Base. All three ant tasks fail to show coherent ant replacement.

For this audit, invalid means that a batch score is used to establish broad coherent concept replacement despite failed controls or format mismatch. P(that conclusion is invalid) is 90-99%. The raw outputs are credible observations, not invalid files. Overall: inconclusive for general concept replacement, narrow positive dog prose evidence, and a negative result for this ant implementation under this wrapper.

Highest-information clues: (1) dog-name changes spider to dog in full prose; (2) ant-legs already emits `6` in Base and then rejects six; (3) ant-name selects sugar glider despite a positive score. These distinguish animal transfer, digit shortcuts, and unrelated animal substitution.

Missing evidence, in order: valid user-role Base/donor controls; fixed executed source for the paired comparison; matched-random/C0 and cross-prompt specificity. No localized steering-code bug is proved here. H1 calls for one prompt-placement test. H2 calls for answer-level evaluation. H4 calls for source comparison before claiming the wrapper caused the change.

Next sequence: first inspect the source changes. Then test only question placement on Base and donor for the same six tasks. This costs about one current batch and carries low risk. If controls become correct, keep that wrapper fixed and rerun the same L23 C2 conditions with C0 and matched-random controls. If controls stay wrong, inspect exact tokenization and normal chat generation before changing steering. Changing wording, placement, layer, and strength together would prevent attribution.

The evidence would change the verdict if valid Base/donor controls plus fixed-code runs showed donor-specific prose on ant tasks. Consistent dog prose under random directions would instead weaken the dog result. All comparisons share one model and related prompts; the six outcomes are not six independent method replications.
