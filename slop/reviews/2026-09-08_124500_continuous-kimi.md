# Review: continuous concept replacement

## Strongest misconception

The method treats a corpus-averaged, unembedding-anchored contrast direction as the *concept* "spider," but everything validated so far is consistent with it being a **lexical bias direction aligned with the dog/ant unembedding rows**. The estimator objective is literally `H @ rows[word]` — a sensitivity of animal-token logits — averaged over unrelated WikiText text. That is close to the best possible recipe for recovering "which direction raises the dog logit," not "which direction encodes the resolved animal in a web-spinning inference." The prompt is critical here: it never names spider. The concept is the output of an implicit multi-hop resolution (spins webs → spider → 8 legs), computed somewhere downstream of the clue tokens. A direction estimated from token-output sensitivity on generic text has no reason to intersect that circuit, and the observed failure signature — digit flips, then retraction, reversion to spider/eight, or riddles — is exactly what lexical overshoot at the answer position looks like while the underlying resolution stays spider. The gate failure fits too: the edit perturbs the answer token, the untouched circuit re-derives spider, and new tokens recreate source dominance.

## Concrete alternative

Replace direction-steering with **activation transplantation from matched clean donor runs** (interchange intervention). Use donors that are structurally parallel to the source prompt — `Fact: The number of legs on the animal that barks is ` / `...that lives in colonies and carries food is ` — so the donor must perform the same implicit-resolution computation. Then: (1) localize where the clue→animal resolution completes via attribution/path patching at the clue phrase and final prompt position, sweeping layers; (2) transplant the donor residual at that position/layer into the source run; (3) decode with no further edits. This transfers a genuine resolved semantic state rather than extrapolating along an estimated direction, and it directly tests whether the concept is a replaceable activation at all. If no single site transplants cleanly, that is itself the answer: the concept is distributed and the linear-subspace framing fails.

## Cheapest matched discriminator

A **logit-bias control matched on first-digit flip rate**: add a scaled dog/ant unembedding bias at the answer position only, tuned so its digit-flip rate equals the C2 edit's, then run the identical continuation evaluation. Cost: a handful of generations, no estimator changes. If the control is indistinguishable from the edit on explanation coherence (retractions, riddles, reversion), the digit flips are fully explained by lexical bias and the current evidence says nothing about concept replacement. If the edit is genuinely better at matched flip rate, lexical bias alone is ruled out. This should run before any further grid expansion.

## Ranked hypotheses with falsifiable predictions

1. **Lexical-bias artifact.** Prediction: edit effect size on the digit correlates with `cos(delta, unembedding row)`; projecting the pair orthogonal to the three unembedding rows kills the flip while a true concept direction would survive. Control test above is decisive.
2. **Overshoot (C2 = 3× sign reversal).** Prediction: a strength sweep shows coherence non-monotone with a peak near the donor margin; but even at the optimum, explanations name the target only at the surface while other spider facts (web-spinning, venom) leak through — distinguishing it from H1 only weakly.
3. **Wrong site: concept resolved downstream, never present at edited positions.** Prediction: donor activation patching finds a late-layer site where transplantation flips *both* digit and explanation coherently, while all direction edits fail on explanation; also, probing residuals after the clue phrase should show spider decodable before the final token.
4. **Suppressed-span projection is noise.** Already supported by your null scan; predict rank-4 projection neither helps nor hurts relative to unprojected at matched strength.

On the donor-margin proposal: it plausibly fixes overshoot (H2) but inherits the same lexical-anchor problem — the margin is measured from the same unembedding geometry. It is a calibration fix, not a semantic one.
