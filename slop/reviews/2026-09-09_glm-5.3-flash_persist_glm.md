# Construction-level persistence test: "Do fixed donor coordinates survive decode?"

## What the test is

**Name:** Fixed-coordinate persistence probe (FCP).

**Construction:** Inject once at a *donor* prompt (spider naming, dog-compatible rule), then decode under a *target* prompt (ant naming) with continuous steering held at fixed strength and fixed layer/coordinates for the entire continuation. Three arms, all in one shared-model `--batch-spec` sweep on the serial GPU:

- **(A) Reference:** donor-prompt decode, C at the working strength (upper bound on what the coordinates can express).
- **(B) Zero-strength:** target-prompt decode, C=0 identity (already available in-sweep as arm 894's clean baseline; run it in the same batch to kill GPU/batch confounds — this is exactly what 888–890 already validated via template-delta cosine 1.0).
- **(C) Test:** target-prompt (ant naming) decode at fixed C, source prompt unchanged throughout.

**Judging rule (common dog+ant):** score *full continuations to EOS or 128 tokens*, not first names. Binary labels: (i) rule-following continuation (the named animal gets the shared rule applied coherently), (ii) reversion (source animal reasserts: spider content, "Wait…" self-correction loops, or name-flip), (iii) degenerate loop. Also log **time-to-reversion in tokens** — the key dependent variable, not the endpoint label. Run both dog and ant targets; dog (893) already behaves, ant (894) is the informative cell.

**What it distinguishes:** if fixed donor coordinates are *appropriate* for the whole decode, continuations in (C) should be rule-following for the target animal at comparable quality to (A). If they become inappropriate as context accumulates, we should see degradation *over tokens* even when the first name is correct (as in 894: correct `蚂蚁` then collapse). If instead the *source prompt* reasserts itself (its residual stream re-dominate as decoding drifts off-distribution), we should see explicit source content migrating in — spider facts, "the animal that spins webs is a spider" (895), or first-token `蜘蛛` (898).

**M2 — Objective/gradient mismatch (the coordinates optimize the donor objective, not persistence).**

Nothing in the selection criterion measures whether those directions stay on-manifold under autoregressive drift. 895 vs 898 is suggestive: sync-attenuation at L24 with high perturbation produces explicit source reassertion ("spider" paragraph); at L20 with low perturbation it produces a name flip to `蜘蛛`. **M3 — Unintended learning dynamic: source-prompt reassertion via decoding feedback.**
